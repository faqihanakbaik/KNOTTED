═══════════════════════════════════════════════════════════════
  DEPLOYMENT STEPS
═══════════════════════════════════════════════════════════════

STEP 1: PUSH TO GITHUB
───────────────────────────────────────────────────────────────
Command:
  git push origin main

Expected: 10 commits pushed successfully

───────────────────────────────────────────────────────────────
STEP 2: RAILWAY PROJECT SETUP
───────────────────────────────────────────────────────────────
1. Go to: https://railway.app
2. Login/Signup with GitHub
3. Click "New Project"
4. Select "Deploy from GitHub repo"
5. Choose repository: KNOTTED
6. Railway will auto-detect Laravel and start building

───────────────────────────────────────────────────────────────
STEP 3: ADD POSTGRESQL DATABASE
───────────────────────────────────────────────────────────────
In Railway project:
1. Click "+ New" button
2. Select "Database"
3. Choose "Add PostgreSQL"
4. Wait for provisioning (1-2 minutes)
5. Database credentials auto-available as: ${{Postgres.DATABASE_URL}}

───────────────────────────────────────────────────────────────
STEP 4: CONFIGURE ENVIRONMENT VARIABLES
───────────────────────────────────────────────────────────────
In Railway service -> Variables tab, add:

REQUIRED VARIABLES:
─────────────────────
APP_NAME=KNOTTED
APP_ENV=production
APP_KEY=<GENERATE_AFTER_FIRST_BUILD>
APP_DEBUG=false
APP_URL=${{RAILWAY_PUBLIC_DOMAIN}}

DB_CONNECTION=pgsql
DB_URL=${{Postgres.DATABASE_URL}}

SESSION_DRIVER=file
SESSION_LIFETIME=120
CACHE_DRIVER=file
QUEUE_CONNECTION=sync

OPTIONAL (for production emails):
─────────────────────────────────
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=hello@knotted.com
MAIL_FROM_NAME=KNOTTED

───────────────────────────────────────────────────────────────
STEP 5: GENERATE APP_KEY
───────────────────────────────────────────────────────────────
After first build completes:
1. Railway service -> Open Terminal (shell icon)
2. Run: php artisan key:generate --show
3. Copy the output (starts with base64:)
4. Add to Railway Variables as APP_KEY
5. Redeploy (Railway will restart automatically)

───────────────────────────────────────────────────────────────
STEP 6: RUN DATABASE MIGRATIONS
───────────────────────────────────────────────────────────────
In Railway terminal:

# Run migrations
php artisan migrate --force

# Create storage symbolic link
php artisan storage:link

# Optimize for production
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan optimize

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════

Error: "could not find driver"
Solution: Check PostgreSQL extensions in composer.json
          Verify build logs show pdo_pgsql installation

Error: "Connection refused"
Solution: Set DB_URL=${{Postgres.DATABASE_URL}}
          Verify Postgres service is running

Error: "No application encryption key"
Solution: Generate APP_KEY and add to variables

Error: "Base table or view not found"
Solution: Run: php artisan migrate --force

Error: Images not showing
Solution: Run: php artisan storage:link
          Check public/storage symlink exists

Error: 500 Internal Server Error
Solution: Check logs: railway logs
          Enable APP_DEBUG=true temporarily
          Check .env variables are set
